# NOVA MEME HUNTER V1.0.0

Dedicated PAPER/SHADOW meme/altcoin hunting bot derived directly from NOVA TRADER V7.0.0, the reference profit core.

## Locked base
- Base profit core: V7.0.0
- Pump/Scalp/Sniper/Launch logic preserved
- PumpPortal realtime + DexScreener retained
- LIVE execution remains hard-locked

## Separation
- Major/perpetual trading is disabled in this bot.
- Non-meme major symbols are filtered from the trading candidate set.
- DOGE and named meme assets remain eligible as meme assets.
- Binance spot may contribute ALT/MEME candidates; Binance Futures and Velocity perps are not used for new entries.

This is not a guarantee of profitability. Validate in PAPER/SHADOW with enough closed trades before any real-money use.
